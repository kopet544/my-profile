PETER — WEBSITE PROFIL DIRI
===========================

TEKNOLOGI
- PHP
- HTML
- CSS
- Tanpa JavaScript dan framework.

STRUKTUR FOLDER
peter_personal_website/
|-- index.php                 Beranda, profil, minat, kontak
|-- journey.php               Halaman perjalanan
|-- thoughts.php              Halaman pemikiran
|-- style.css                 Semua pengaturan tampilan
|-- includes/
    |-- header.php            Head HTML dan navbar
    |-- footer.php            Footer website

CARA MENJALANKAN DI XAMPP
1. Ekstrak folder peter_personal_website ke C:\xampp\htdocs\
2. Jalankan Apache dari XAMPP Control Panel.
3. Buka http://localhost/peter_personal_website/

PANDUAN MENGEDIT
- Profil, hobi, minat, dan kontak: index.php
- Perjalanan/linimasa: journey.php
- Tulisan dan catatan: thoughts.php
- Warna, ukuran, jarak, dan layout: style.css
- Navbar: includes/header.php
- Footer: includes/footer.php

CATATAN
- Foto utama masih placeholder; ganti dengan foto pribadi jika sudah siap.
- Ganti hello@example.com di index.php dengan email aktif.
- Isi perjalanan dan pemikiran adalah contoh awal. Sesuaikan dengan pengalaman
  dan pandangan pribadi sebelum website dipublikasikan.
